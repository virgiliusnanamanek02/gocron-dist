# Contributing to gocron-dist

First off, thank you for considering contributing to **gocron-dist**! It's people like you that make the open-source community such an amazing place to learn, inspire, and create.

## How Can I Contribute?

### Reporting Bugs

- Use the [GitHub Issue Tracker](https://github.com/virgiliusnanamanek02/gocron-dist/issues).
- Describe the bug and include steps to reproduce.
- Mention your Go version and OS.

### Suggesting Enhancements

- Open an issue with a clear title and description of the proposed feature.
- Explain why this enhancement would be useful to most users.

### Pull Requests

1. Fork the repository.
2. Create a new branch (`git checkout -b feature/my-new-feature`).
3. Make your changes.
4. Ensure your code follows Go best practices.
5. Run tests: `go test ./...`.
6. Run the linter: `golangci-lint run`.
7. Commit your changes (`git commit -m 'feat: add some amazing feature'`).
8. Push to the branch (`git push origin feature/my-new-feature`).
9. Open a Pull Request.

## Local Development Setup

- **Go Version**: 1.24 or higher.
- **Dependencies**: Managed via Go modules. Run `go mod download`.
- **Linting**: We use `golangci-lint`. Please ensure it passes before submitting a PR.

## Code of Conduct

Please be respectful and professional in all interactions within the project.
